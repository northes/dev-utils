# AGENTS.md

Wails v3 (beta) desktop tray app: Go backend + React 19 frontend. Local-first developer utility launcher. UI is the product; Go layer is a thin shell.

## Commands

- Run all tasks through `wails3 task <name>` — bare `task`/go-task is not installed; the wails3 CLI bundles it. `Taskfile.yml` is the source of truth (the stock README's `wails3 dev` is stale).
- `wails3 task dev` — dev loop: builds a DEV binary, starts Vite on port 9245 (override with `WAILS_VITE_PORT`), hot-reloads Go on `*.go` changes (watcher config in `build/config.yml`) while Vite handles the frontend.
- `wails3 task build` / `package` / `run` — dispatch to `build/{GOOS}/Taskfile.yml`.
- Frontend deps: `npm install` inside `frontend/` only (repo root has no package.json). Frontend build = `tsc && vite build`; `main.go` embeds `frontend/dist` via `//go:embed all:frontend/dist`, so dist must exist for any Go build.
- No lint/format tooling configured (no eslint/prettier/golangci). Type-check: run `npx tsc --noEmit` in `frontend/`. No tests exist.

## Architecture

- `main.go` is the entire Go side: one window, system tray menu, no services. **No Go services are bound** — `greetservice.go` is an unused template leftover; the frontend cannot call Go methods. Go→frontend communication is only via `app.Event.Emit` / `Events.On` (tray "Settings" emits `navigate`, handled in `frontend/src/App.tsx`).
- Window close hides to tray instead of quitting (`WindowClosing` hook calls `Hide()` + `Cancel()`); quit is tray-menu only. App is a Mac accessory (`ActivationPolicyAccessory`), so there is no normal Dock window.
- `go.mod` module name is still the template default `changeme` — don't be surprised; use real import paths when adding deps.
- `build/config.yml` holds build-asset metadata (info fields are still "My Company" placeholders). Editing it requires `wails3 task common:update:build-assets`, which regenerates/overwrites assets.
- `frontend/bindings/` is generated by the wails Vite plugin and is committed — never hand-edit.

## Frontend conventions

- All UI is in `frontend/src/App.tsx`, intentionally minified single-line style (component-per-line, minimal spacing). Do not reformat or pretty-print it; match the dense style when editing.
- All styling lives in `frontend/src/index.css` using CSS custom properties (dark-only theme: `--bg`, `--surface`, `--accent`, …). Body is `user-select:none`.
- HeroUI (`@heroui/react`): use HeroUI props, not standard DOM — `Button` fires `onPress`, `Switch` takes `isSelected` + `onChange`. Consult `frontend/.agents/skills/heroui-react/SKILL.md` before using other HeroUI components.
- Icons from `@phosphor-icons/react`. Font is Inter (local TTF in `frontend/public/`).
- Window drag regions are controlled by `--wails-draggable: drag/no-drag` CSS on elements (titlebar uses `data-wails-drag`), not via JS.
- Persisted state via localStorage keys `devutils.favorites`, `devutils.history`, `devutils.settings`.
- `frontend/.npmrc` sets `minimum-release-age=10080` (supply-chain policy; honored by pnpm/bun, ignored by npm).
